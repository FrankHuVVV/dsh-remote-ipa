## 5. 平台与安全

| 能力 | 鸿蒙版 | iOS 版 | 状态 | 说明 |
|---|---|---|---|---|
| 令牌加密存储 | AES-256-GCM + 偏好 | **系统钥匙串** | ✅ | ADR-0003 |
| 不参与云备份 | 有 | `this_device` | ✅ | |
| 不使用 WebView | 是 | 是 | ✅ | ADR-0001 |
| 前后台事件流 | 熄屏断流 / 亮屏恢复 | 同 | ✅ | |
| 本地网络权限 | 无此概念 | `NSLocalNetworkUsageDescription` | 🟡 | 真机第一次连接会弹权限 |
| ATS 明文 | 不适用 | 仅 `NSAllowsLocalNetworking` | 🟡 | 公网中继必须 https |
| 文件 App 可见（导出） | 系统面板 | `UIFileSharingEnabled` | 🟡 | 未在真机确认 |
| 系统选择器（附件 / 上传） | `@ohos.file.picker` | `image_picker` + `file_picker 13` | 🟡 | 附件可选「图库 / 文件」两个来源 |

### 仍不做的（理由）

- **图片存入相册**：要走 `PHPhotoLibrary` + 权限被拒的降级路径，而「导出到文件」已经覆盖
  「把图拿出来」的真实需求。差异记录为 🔵，不是遗漏。
- **供应商凭据「显示」**：服务端从不回传 apiKey，客户端也不该造一个能显示它的输入框。
- **会话列表行内摘要**：需要为每台会话额外拉一次历史，列表滚动时会放大流量；
  目前放在会话洞察面板里按需加载。
